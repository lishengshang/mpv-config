# 共享决策记录

只记录影响后续开发的选择。每条写明状态、理由、适用范围、证据和替代关系。

## DEC-001：使用仓库文件作为跨工具交接入口

- 日期：2026-10-14。
- 状态：当前采用。
- 背景：Trae、Zcode、WorkBuddy、GPT 的私人记忆与工作记录不能作为其他工具可访问的项目状态。
- 决定：共享规则放 `AGENTS.md`，当前状态放 `PROJECT_STATE.md`，任务交接放 `docs/tasks/`，重要决定放本文件；各工具通过统一开场提示读取。
- 边界：这些文件不自动同步聊天、不提供文件锁，也不证明功能已运行通过；跨 checkout 用 Git 或补丁传递，无法访问仓库的工具需提供记录副本。
- 相关任务：`COORD-001`；协议见 `docs/collaboration.md`。

## DEC-002：基础配置与 RTX VS 增强包分开

- 日期：2026-10-14。
- 状态：当前采用；用户已选择只针对 NVIDIA RTX、实时优先、VS 大包可选。
- 决定：基础配置附带上游 ArtCNN C4F16/C4F32 GPU shader；VS 使用独立可选压缩包，解压到 mpv 同级。不自动开启重画质/降噪/补帧。
- 实现：新增上游 k7sfunc Bilateral/DFTTest CUDA 调用预设；使用上游 7-Zip 导出本机便携运行时和模型，排除私人配置与引擎缓存；另提供上游包导入工具。
- 理由：仅 portable_config 无法携带 Python/VS 与模型；分包让基础播放轻量，新电脑可选择完整增强。
- 边界：GPU 核心算法复用上游；CPU 格式转换与调度仍存在。合成源产帧只能证明可运行，不能保证所有片源画质或实时速度。
- 相关任务：`VS-001`；说明见 `docs/gpu-setup.md`。
