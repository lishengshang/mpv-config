# 目录用途与清理边界

根目录是 mpv 约定的配置入口，保持现有布局。开发文档与检查工具分别放 `docs/`、`tools/`；开发文件不应被当作垃圾。

| 位置 | 用途 | 清理原则 |
| --- | --- | --- |
| 根目录 `.conf`、`manager.json` | 配置、快捷键、菜单、配置组与脚本管理 | 保留，联动修改 |
| `local.conf` | 当前机器路径与私人设置，Git 忽略 | 保留；迁移时按新机器重配 |
| `scripts/`、`script-modules/`、`script-opts/` | 启用的脚本及其依赖与选项 | 查清调用关系后再移除 |
| `vs/`、`shaders/` | VS 调用预设与 GPU 着色器 | 保留正在使用的内容与来源说明 |
| `fonts/`、`icc/`、`osc-style/` | 字体、色彩与界面资源 | 根据配置引用处理，不批量删除 |
| `archive/` | 已停用组件与历史备份 | 保留；空间约 2.4MiB，默认不启用 |
| `AGENTS.md`、`PROJECT_STATE.md`、`docs/` | 多工具规范、进度、决定、交接与验证摘要 | 保留并维护，避免工具各自重复探索 |
| `tools/` | 部署、导出、自检与回归入口 | 保留；不自动当作播放器 Lua 脚本加载 |
| `cache/packages/` | 正式配置与可选 VS 增强包、SHA256 | 按交付需要保留；VS 大包是主要剩余占用 |
| `cache/gpu-check/`、`cache/gpu-keybind-test.log` | 本机验证日志、截图和 JSON 证据 | 本轮保留，后续保留摘要后可定期清理 |
| `cache/shaders_cache/` | 正常 shader 缓存 | 保留可减少重新编译；清空后可重建 |
| `cache/watch_later/`、`files/` | 播放进度、历史与运行状态 | 保留；清理会丢失用户状态 |
| `.git` | 子模块 Git 入口，元数据实际位于父仓库 | 不删除或搬动 |

2026-10-14 的 `CLEAN-001` 已清理独立迁移运行时、无 VS 基础测试目录、导入预览目录、旧配置 ZIP 和打包临时清单，约释放 4.8GiB。正式交付包与主验证证据保留。

后续遵循：先看用途与占用，明确临时文件来源，再确认绝对路径与链接，最后仅删除指定目标。不要使用 `git clean -fdx` 或直接删除整个 `cache/`、`files/`；这些位置也存放需要保留的交付包和播放状态。

导出工具在成功生成压缩包与校验文件后会删除自身临时 `.lst`；导出失败时保留清单用于排查。正式包属于 `VS-001` 快照，本轮只改清理记录与打包工具，未重建 GPU 大包。
